## BUILD
If you are going to build this project on your local PC, remember:
* Install CMake (At least of version 3.28.3)
```bash
sudo apt install cmake
```
* Install Json-C
```bash
sudo apt install libjson-c-dev 
```
* Install QT (At least of version Qt-6, at path ~/libs/qt)

[Qt Remote](https://qt.io)

## RUN
In theory, this project can run on multiple platforms (including android ones), but the project itself will only be built on Linux, so the capability isn't sure
